# A股盘后选股系统设计(配套主升浪突破策略)

> 配套文档:`strategies/ashare-leader-breakout.md`
> 运行时机:每个交易日 **15:30 之后**(待交易所行情/龙虎榜/资金流数据落地)
> 产出:**次日候选池 Top N**(主攻 / 守正 / 观察 / 黑名单四档),含买入计划与风控参数
> 设计目标:**自动化、可复盘、可回测、不依赖盘中盯盘**

## 2. 数据输入

| 类别 | 字段 | 数据源建议 |
|------|------|-----------|
| 日线行情 | OHLCV、换手率、振幅、流通市值、总市值 | Tushare Pro / AKShare / 聚宽 / Wind |
| 分时数据 | 1分钟K线(用于计算封板时间、尾盘量能) | AKShare / Wind |
| 涨跌停明细 | 首次/最终封板时间、封单金额、炸板次数、连板数 | 同花顺/东财/AKShare `stock_zh_a_st_em` |
| 龙虎榜 | 营业部席位、买卖金额、净买入、知名游资标签 | 东财/同花顺,人工维护游资席位字典 |
| 资金流 | 主力净流入、超大单/大单、北向持股变动 | AKShare / 同花顺 |
| 板块题材 | 同花顺/东财概念归类、板块涨幅、连板梯队 | 同花顺/东财 |
| 公告与基本面 | 业绩预告、定增、解禁、ST、风险提示 | 巨潮资讯 / Wind |
| 大盘指标 | 上证、创业板指、两市成交额、涨停家数、昨日涨停溢价指数 | 聚合自上 |

> **数据时效性要求**:涨跌停明细与龙虎榜在 15:30–17:00 陆续更新完毕,选股任务建议 **17:30 准点跑**。如果使用免费源(AKShare),需对失败重试 + 兜底数据缓存。

## 3. 数据清洗与特征工程

每个标的当日生成一行特征向量(`stock_id, trade_date, features...`):

### 3.1 量价特征
- `pct_change`:当日涨跌幅
- `turnover_rate`:换手率
- `vol_ratio_5/20`:量比(成交量 / N 日均量)
- `price_pos_60`:当前价相对 60 日最高/最低的位置(0–1)
- `dist_ma60/ma120`:距 60/120 日均线百分比
- `n_day_return_5/10/20`:近 N 日累计涨幅
- `amp`:振幅
- `intraday_strength`:(收盘 - 当日均价) / 当日均价

### 3.2 涨停特征
- `is_zt`:是否涨停
- `zt_first_time`:首次封板时间(分钟数,9:30=0)
- `zt_final_time`:最终封板时间
- `zt_open_times`:炸板次数
- `seal_amount`:封单金额
- `seal_ratio_to_circ`:封单 / 流通市值
- `seal_ratio_to_amount`:封单 / 当日成交额
- `consec_zt`:连板数
- `is_one_word`:是否一字板
- `is_t_word`:是否 T 字板

### 3.3 资金/席位特征
- `net_main_inflow`:主力净流入
- `super_large_net`:超大单净额
- `lhb_net_buy`:龙虎榜净买入
- `hot_money_count`:知名游资席位上榜数(对照游资字典)
- `inst_net_buy`:机构席位净买卖
- `north_hold_change`:北向持股变化

### 3.4 板块/题材特征
- `sector_rank`:个股在板块涨幅榜的位次
- `sector_zt_count`:所属板块当日涨停家数
- `sector_height`:板块当日最高连板高度
- `is_sector_leader`:是否板块龙一(首先涨停 + 最高连板)
- `theme_heat_3d`:题材近 3 日热度(板块成交额 / 5 日均值)

### 3.5 风险标记(直接打入黑名单)
- `is_st`:ST/*ST
- `risk_warning`:重大风险提示/退市风险
- `recent_listed`:上市 < 60 个交易日(次新过滤可选)
- `pending_unlock_30d`:30 日内大额解禁
- `pending_earnings_neg`:业绩预亏未消化

## 4. 分层过滤(硬规则,先做剪枝)

### 4.1 全局闸门(大盘环境)
当日**任一不满足**则系统**只输出观察池,不生成主攻/守正名单**:

| 指标 | 阈值 |
|------|------|
| 上证 5 日均线 ≥ 20 日均线 | 必须 |
| 当日涨停 / 跌停 | ≥ 5,且涨停 ≥ 50 |
| 市场最高连板 | ≥ 3 |
| 昨涨停溢价指数(3 日均) | > -1% |
| 两市成交额 | ≥ 8000 亿且 ≥ 5 日均 |

### 4.2 个股黑名单(直接剔除)
- `is_st = 1` 或 `risk_warning = 1`
- `circ_mv < 20亿` 或 `circ_mv > 150亿`
- `n_day_return_5 ≥ 60%`(高位接力)
- `is_one_word = 1`(一字无买点)
- `pending_unlock_30d = 1` 且解禁规模 > 流通 10%
- `recent_listed = 1` 且未开板(次新独立池)

### 4.3 候选层(进入打分的最低门槛)
满足以下 **任一身份**,进入打分环节:

1. **首板龙头候选**:`is_zt=1` 且 `consec_zt=1` 且 `zt_first_time ≤ 30分钟` 且 `seal_ratio_to_circ ≥ 1.5%`
2. **连板梯队候选**:`is_zt=1` 且 `consec_zt ≥ 2` 且 `is_sector_leader=1`
3. **突破启动候选**:非涨停但满足
   - `pct_change ≥ 5%` 且 `vol_ratio_5 ≥ 2` 且 `dist_ma60 ≥ 0` 且 `price_pos_60 ≥ 0.7`
   - 且板块当日 `sector_zt_count ≥ 3`(板块共振)

## 5. 综合打分模型

每只候选股计算 0–100 综合得分,由四个子项加权:

```
total_score = 0.35 * leader_score        # 龙头身份
            + 0.25 * momentum_score      # 量价动量
            + 0.20 * capital_score       # 资金/席位
            + 0.20 * sector_score        # 板块共振
            - penalty                    # 风险扣分
```

### 5.1 leader_score(龙头身份,0–100)
- 板块龙一:+50
- 连板高度(每板 +10,封顶 +30)
- 早盘封板(`zt_first_time ≤ 15min`):+15;15–30 分钟:+8
- 封单 / 流通市值 ≥ 3%:+15;1.5%–3%:+8
- 当日**未炸板**:+5;炸板 1 次:0;≥ 2 次:-10

### 5.2 momentum_score(量价动量,0–100)
- `vol_ratio_5` ∈ [2, 5]:满分 30(过低/过高线性扣分,> 8 视为天量警告 -10)
- 收盘价 ≥ 当日均价:+15
- `dist_ma60 ≥ 0`(均线之上):+15
- `price_pos_60 ≥ 0.8`(强势位):+20;0.6–0.8:+10
- `intraday_strength ≥ 1%`(尾盘强势):+20

### 5.3 capital_score(资金/席位,0–100)
- 主力净流入 > 流通市值 1%:+25
- 龙虎榜净买入 > 0:+20
- 知名游资席位上榜 ≥ 2 家:+25;1 家:+10
- 北向当日加仓:+15
- 机构净卖出且龙虎榜显示机构出货:-30(出货标记)
- 一日游游资席位(对照黑名单字典):-15

### 5.4 sector_score(板块共振,0–100)
- 所属板块连板高度 ≥ 3:+30
- 板块涨停家数 ≥ 5:+25
- 板块 3 日热度 > 1.5:+20
- 题材有政策/业绩催化(标签字典命中):+25
- 板块第二梯队已大面积炸板:-30(末端风险)

### 5.5 风险扣分(penalty)
- 5 日涨幅 40–60%:-15
- 上市 < 90 个交易日且非首板:-10
- 当日成交额 / 5 日均 > 6:-10(天量分歧)
- 月内已被监管异常交易提醒:-25

## 6. 候选池分档

按 `total_score` + 当日大盘闸门状态分档:

| 档位 | 条件 | 计划仓位上限 |
|------|------|--------------|
| **主攻 (S)** | 大盘闸门全开 + score ≥ 80 + 是板块龙一 | 25–30% |
| **守正 (A)** | 大盘闸门全开 + score 70–80 | 10–15% |
| **观察 (B)** | score 60–70,或大盘闸门有 1 项不满足 | 不开仓,只跟踪 |
| **黑名单 (X)** | 命中 §4.2 任一项,或 score < 50 | 永不交易 |

每日主攻档 ≤ 3 只、守正档 ≤ 5 只,**总候选 ≤ 10**(防止注意力分散)。

## 7. 次日交易计划生成

对每只主攻/守正股票,系统输出结构化计划:

```yaml
- code: 600000
  name: 示例股份
  tier: S
  score: 86
  sector: 人工智能
  reason:
    - 板块龙一,首板封单 4.2% 流通市值
    - 9:36 封板,无炸板
    - 龙虎榜知名游资 3 席净买入 1.2 亿
    - 板块今日 7 个涨停,3 日热度 1.8
  plan:
    bid_range: [3.0%, 7.0%]            # 竞价高开区间
    entry_trigger: "竞价 +5% 内 + 9:30 后突破前高放量"
    abort_if:
      - "竞价低开 < +1% 或高开 > +8%"
      - "9:45 前跌破均价线 1.5%"
      - "板块第二梯队开盘 30 分钟内炸板 ≥ 2 只"
    position_pct: 25
    stop_loss_pct: -4
    target_take_profit:
      - "T+1 涨停 → T+2 减仓 1/2"
      - "T+1 出现长上影/放量背离 → 全部止盈"
    notes: "题材有政策催化,留意 8:30 政策窗口的预期变化"
```

并附**当日市场画像**:大盘闸门状态、连板梯队结构、亏钱效应、风险提示,便于次日早盘决策。

## 8. 输出与告警

- **JSON 落库**:`candidates_{YYYYMMDD}.json`,含全部候选 + 评分明细,用于回测与复盘。
- **Markdown 报告**:`reports/{YYYYMMDD}.md`,主攻/守正/观察分档展示,人类可读。
- **Webhook 推送**(微信/飞书/Telegram):
  - 17:35 推送主攻 + 守正名单 + 简要理由
  - 21:00 推送复盘提醒(对昨日候选打开盘后表现回写)
- **关键告警**(独立通道):
  - 大盘闸门状态翻转(由开转关 / 由关转开)
  - 候选股出现公告类风险(立即移出主攻档)
  - 知名游资集中上榜某板块 → 次日板块预警

## 9. 工程实现建议

### 9.1 目录结构
```
strategies/ashare_screener/
├── config/
│   ├── thresholds.yaml          # 全部阈值集中管理
│   ├── hot_money_seats.yaml     # 知名游资席位字典
│   ├── theme_keywords.yaml      # 题材关键词与催化标签
│   └── blacklist.yaml           # 长期黑名单(雷股、问题公司)
├── data/
│   ├── ingestion/               # 各数据源 adapter(可插拔)
│   ├── cache/                   # 本地缓存(parquet)
│   └── lake/                    # 历史归档
├── features/
│   ├── price_volume.py
│   ├── limit_up.py
│   ├── capital_flow.py
│   └── sector.py
├── pipeline/
│   ├── filter.py                # §4 分层过滤
│   ├── score.py                 # §5 打分
│   ├── tier.py                  # §6 分档
│   └── plan.py                  # §7 计划生成
├── output/
│   ├── reporter.py              # Markdown / JSON
│   └── notifier.py              # Webhook
├── backtest/
│   ├── engine.py                # 历史回放
│   └── metrics.py               # 胜率/盈亏比/最大回撤
└── run_daily.py                 # 入口,15:30/17:30 调度
```

### 9.2 调度
- Linux cron:`30 17 * * 1-5 /usr/bin/python /path/run_daily.py`,只在交易日运行(用 `chinese_calendar` 判定)。
- 或 Airflow DAG,失败重试 3 次,数据缺失自动降级到上一交易日缓存并标注。

### 9.3 工程要点
- **阈值全部进 yaml**,不写死在代码里,便于回测扫参。
- **每个特征单测**,避免数据源字段名变化导致全链路崩溃。
- **特征版本化**(feature schema versioning),回测和实盘共用一套特征,杜绝训练-推理不一致。
- **失败可观测**:每个数据源单独打点,Prometheus / 简易日志均可。
- **复盘自动化**:每日 21:00 把候选股 T+1 表现写回数据库,自动统计主攻档胜率与盈亏比。

## 10. 回测要求(上线前必做)

- 样本期至少 3 年,覆盖 2022–2025 多种市场状态。
- 必须真实建模:
  - **涨停板成交概率** = f(封单 / 成交、连板数、板块强度);不能假设全成交。
  - **滑点**:候选股次日开盘单按当日成交额 0.5%–1% 估算;盘中触发追价 +0.3%。
  - **税费**:佣金 0.025%、印花税 0.05%(卖出)、过户费 0.001%。
- 输出指标:
  - 胜率、平均收益、盈亏比
  - 主攻档 vs 守正档 vs 观察档对比
  - 大盘闸门关闭日的"假信号"率(应接近 0,验证闸门有效性)
  - 资金曲线、最大回撤、卡玛比
- **样本外**:留出最近 3 个月作为 OOS,只看不调,过拟合的模型禁止上实盘。

## 11. 边界与风险

- 系统输出的是**候选与计划**,不替代盘中执行;盘中仍需结合竞价、分时形态、板块联动做最终判定。
- 数据源滞后/缺失会导致打分失真,**当日数据不全时,系统应主动降级输出"低置信度"标记**,而不是给出无效的高分名单。
- 监管收紧期(异常交易提醒密集、龙虎榜处罚增加)应**临时下调主攻档仓位上限**,可在 `thresholds.yaml` 中加一个 `regulation_mode` 全局乘子。
- 系统是**辅助工具**,不是黑盒交易机器人,关键判断仍由交易者负责;"不开仓"永远是合法选项。

---

## 12. 一句话总结

> **每日 17:30 跑一次:大盘闸门→ 黑名单剔除 → 候选层身份判定 → 四维打分 → 分档输出主攻/守正/观察 → 生成次日计划与告警。可回测、可复盘、可迭代。**
